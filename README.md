# Python OOP & DSA Practice Repository.

## 📖 Overview
This repository contains multiple Python programs created to practice **Object-Oriented Programming (OOP)** concepts, **Data Structures**, and **real-world problem modeling**.  
Each file focuses on a specific concept or use case, making the repository modular and easy to understand.

---

## 🧠 Concepts Covered
- Object-Oriented Programming (OOP)
- Inheritance & Encapsulation
- Classes and Objects
- Data Structures (Stack)
- Python Modules & Packages
- Real-world system modeling

---

## 📁 File-wise Documentation (README for All Files)

### 1️⃣ `BankAccount.py`
📌 **Description:**  
Base class for banking operations.  
Defines common attributes and methods used by all account types.

🔹 **Key Concepts Used:**
- Class & Object
- Encapsulation
- Methods (deposit, withdraw, balance display)

---

### 2️⃣ `SavingAccount.py`
📌 **Description:**  
Implements a **Savings Account** using inheritance from `BankAccount`.

🔹 **Key Concepts Used:**
- Inheritance
- Method overriding
- Interest calculation

---

### 3️⃣ `CurrentAccount.py`
📌 **Description:**  
Represents a **Current Account** with different rules (e.g. minimum balance).

🔹 **Key Concepts Used:**
- Inheritance
- Business rule implementation
- Conditional logic

---

### 4️⃣ `FixedDeposit.py`
📌 **Description:**  
Models a **Fixed Deposit Account** where money is locked for a fixed duration.

🔹 **Key Concepts Used:**
- Class design
- Interest calculation
- Real-world banking logic

---

### 5️⃣ `demo.py`
📌 **Description:**  
Demo / execution file used to test and run all banking classes.

🔹 **Purpose:**
- Object creation
- Method calling
- Output verification
