## 💻 Getting Started

Follow these steps to set up and run an individual Python project.

### Prerequisites

Install the following tools:

- [Python](https://www.python.org/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)
- Google Chrome or another supported browser for browser automation projects

Some projects may require additional packages, database software, or configuration.

### 1. Clone the Repository

```bash
git clone https://github.com/sachinkharat05/Python.git
```

### 2. Navigate to the Repository

```bash
cd Python
```

### 3. Select a Project

Navigate to the project folder you want to run.

Example:

```bash
cd LearnPython
```

### 4. Check Python Installation

```bash
python --version
```

### 5. Create a Virtual Environment

```bash
python -m venv venv
```

### 6. Activate the Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

For macOS or Linux:

```bash
source venv/bin/activate
```

### 7. Install Dependencies

If the project contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

If the project does not contain a requirements file, install the dependencies specified in its documentation.

## ▶️ Running Python Applications

Navigate to the appropriate project folder.

Run the Python application:

```bash
python app.py
```

Replace `app.py` with the actual Python entry-point filename.

For example:

```bash
python filename.py
```

For Flask, FastAPI, and other framework-based projects, follow the project's specific startup instructions.

---

## 🌐 Running Flask Applications

For projects developed using Flask:

1. Navigate to the Flask project folder.
2. Activate the virtual environment.
3. Install the required dependencies.
4. Check the application entry point.
5. Start the application.

Example:

```bash
python app.py
```

Open the local URL displayed in the terminal.

A Flask development server commonly uses:

```text
http://127.0.0.1:5000/
```

The actual port depends on the application configuration.

---

## ⚡ Running FastAPI Applications

For projects developed using FastAPI:

1. Navigate to the FastAPI project folder.
2. Activate the virtual environment.
3. Install the required dependencies.
4. Identify the FastAPI application entry point.
5. Start the application using Uvicorn.

Example:

```bash
uvicorn main:app --reload
```

Open the application URL displayed in the terminal.

FastAPI applications commonly provide interactive API documentation at:

```text
http://127.0.0.1:8000/docs
```

The actual URL depends on the application's configuration.

## 🧪 Browser Automation Testing

Some projects use Playwright and pytest for automated browser testing.

### Install Dependencies

```bash
pip install pytest playwright
```

### Install Playwright Browsers

```bash
playwright install
```

### Run All Tests

```bash
pytest
```

### Run Tests with Detailed Output

```bash
pytest -v
```

### Run a Specific Test File

```bash
pytest test_login.py -v
```

Replace `test_login.py` with the actual test filename.

### Run Tests in Headless Mode

Headless execution runs browser tests without displaying the browser window.

The actual browser mode depends on the test configuration.
